META PIXEL + CONVERSIONS API — AERIS ONE
========================================

CE ESTE DEJA INSTALAT PE SITE
- Meta Pixel ID 1576911387464284, acelasi dataset folosit pentru smartwatch.
- PageView pe toate paginile, ViewContent pe produs, InitiateCheckout pe formular
  si Purchase pe pagina thank-you dupa trimiterea reala a formularului.
- Scriptul Adrice trk.min.js pe index.html, order.html si thank-you.html.
- Pixelul de impresie Adrice pentru offer 2713, uid-ul tau si lp 2746.
- Formularul API Adrice si redirectarea la thank-you.html dupa comanda.

NU ADAUGA TOKENUL META IN FISIERELE SITE-ULUI.
Tokenul Conversions API este secret si trebuie introdus numai in Adrice.

PASUL 1 — FOLOSESTE DATASETUL EXISTENT
Nu mai crea o sursa Web noua. Deschide datasetul "smartwatch" cu Pixel ID:
1576911387464284

In Settings verifica Traffic permissions. Daca folosesti un allow list, adauga:
romaniandrone.store
www.romaniandrone.store

PASUL 2 — OBTINE ACCESUL CONVERSIONS API
1. In Events Manager, deschide datasetul smartwatch.
2. Intra la Settings / Setari.
3. Gaseste Conversions API si alege configurarea manuala sau generarea tokenului.
4. Copiaza tokenul si pastreaza-l privat.

PASUL 3 — CONECTEAZA PIXELUL IN ADRICE
1. Deschide oferta 2713 in Adrice.
2. In sectiunea Meta conversions API apasa Manage data sources.
3. Apasa Add new si introdu numele "Romanian Drone", Pixel ID
   1576911387464284 si tokenul cerut.
4. Revino la oferta 2713, activeaza sursa si alege eventul Lead.
5. Pentru formularul trimis, foloseste statusul New/Pending ca trigger.
6. Lasa Custom purchase value dezactivat pentru eventul Lead si apasa Save.

PASUL 4 — TESTARE
1. In Meta Events Manager deschide Test events.
2. Deschide https://www.romaniandrone.store/ intr-o fereastra incognito.
3. Trimite o singura comanda de test valida si verifica PageView, ViewContent,
   InitiateCheckout si Purchase.
4. Dupa conectarea Adrice CAPI, verifica si eventul server Lead.

DESPRE PURCHASE
Purchase este trimis din browser numai dupa formular si o singura data in acea
sesiune. Valoarea folosita este pretul real al comenzii: 349 RON. Valoarea de
15 EUR din Adrice este payout-ul afiliatului, nu valoarea platita de client.

DESPRE SEARCH
Eventul Search nu este instalat deoarece site-ul nu contine cautare. Trimiterea
lui pe o pagina normala ar crea date false in Meta. Daca se adauga ulterior o
functie reala de cautare, eventul trebuie declansat numai dupa cautarea clientului.

DESPRE SHORT LINK
https://offers.adricenetwork.com/Ruvjq5K2 este link de tracking, nu cod care
trebuie pus in formular. In captura Adrice, Your landing page este N/A. Nu folosi
acest short link in reclama pana cand setezi romaniandrone.store ca landing page
in Adrice si generezi/verifici din nou linkul. Pentru reclama poti folosi direct:
https://www.romaniandrone.store/

PARAMETRI RECOMANDATI IN META ADS
In campul URL parameters al reclamei poti introduce:
utm_source=facebook&utm_medium=paid_social&utm_campaign={{campaign.name}}&utm_content={{ad.name}}&subid={{ad.id}}&subid2={{adset.id}}&subid3={{campaign.id}}

Site-ul pastreaza automat acesti parametri cand vizitatorul trece de la pagina
principala la formular si ii trimite impreuna cu comanda catre Adrice.
